# ZF-001 — Yang et al. (2021)

## Citation

Yang P, Takahashi H, Murase M, Itoh M. *Zebrafish behavior feature recognition using three-dimensional tracking and machine learning.* Scientific Reports. 2021;11:13492. DOI: 10.1038/s41598-021-92854-0.

## Why I Read It

Direct adult-zebrafish ML precedent combining 3D tracking, temporal segmentation, dimensionality reduction, unsupervised clustering, and stimulus association.

## Research Question

Can machine learning identify behavior features associated with electric shock from 3D zebrafish trajectories?

## Data

- Adult zebrafish.
- Two-camera 3D tracking.
- Electric-stimulus experiment.

## Method

- 3D trajectory reconstruction.
- Temporal segmentation.
- PCA-related dimensionality reduction.
- FuzzyART unsupervised clustering.
- Grid search over temporal segmentation, explained variance, and vigilance-related settings.

## Behavioral Representation

Tracking-derived temporal/trajectory features.

## Discovery Method

Fuzzy adaptive resonance theory (FuzzyART).

## Validation

- Electric-stimulus association tested statistically.
- Behavior manually observed alongside recordings.
- Parameter grid search performed.
- No explicit held-out-fish, identity-leakage, or speed-confound battery identified.

## Main Result

Machine-learned behavioral features were statistically linked to electric stimulation.

## Limitations for Present Project

Grid-search-based parameter choice illustrates the need to isolate tuning from held-out final evaluation.

## What This Means for Zebrafish SSL

Unsupervised adult-zebrafish ML discovery already exists.
